# 🧠 Mind Pattern Detective

📌 Project Overview
-------------------
The **Mind Pattern Detective** is a Python-based, menu-driven console application designed to challenge users with logical patterns and mathematical puzzles. The system allows users to solve levels involving **number series, sequences, and hidden rule patterns**.

This project is built to demonstrate core **Python programming concepts** including conditional statements, loops, strings, collections, and input validation.

🎯 Objectives
-------------
* Build an interactive logic-based puzzle game
* Demonstrate fundamental Python programming concepts
* Test analytical thinking through number patterns
* Ensure proper user input validation and execution

🛠️ Features
------------
* 🔢 **LEVEL-01: Number DNA** — Solve complex number series puzzles
* 📈 **LEVEL-02: Sequence Puzzle** — Identify and complete arithmetic sequences
* 🧩 **LEVEL-03: Hidden Rule** — Discover hidden pattern logic to find the correct answer

🧠 Concepts Used
----------------

✅ **Python Fundamentals**
* Variables & Datatypes
* Type Casting (`int()`)
* Operators
* Input/Output operations

✅ **Control Flow**
* `if-else` statements
* Menu-based decision handling

✅ **Looping**
* `for` loops for iterating over sequence items
* `range()` function for loop indexing

✅ **Collections**
* `list` to store sequence numbers
