Logic Box – Pattern Logic 🧠

## 📌 Project Description
Logic Box is a simple Python project that helps users understand **patterns and basic programming logic** using `for` loops, `if-elif-else`, `range()`, and `%` (modulus).

The project contains two pattern challenges:
1. **Pattern Logic**
2. **Butterfly Pattern**
3. **Dimond pattern**

The user enters a number, and Python generates the pattern according to hidden rules.

## 🎯 Objectives
- Learn how `for` loops work.
- Understand `if`, `elif`, and `else` conditions.
- Practice the `range()` function.
- Understand even, odd, and divisible-by-3 numbers.
- Generate patterns using symbols.

## 🔹 Pattern Logic
The first challenge uses different symbols based on the row number:

- If the row number is divisible by **3**, it prints `@`.
- Else if the row number is **even**, it prints `#`.
- Otherwise, it prints `*`.

The number of symbols in each row is equal to the row number.

### Example
For input `5`:

```text
*
# #
@ @ @
# # # #
* * * * *
```
